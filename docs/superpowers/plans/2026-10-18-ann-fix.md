# ann_fix (validator-warning resolver on .ann) + gff2mss fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new `ann_fix` subtool that reads a gff2mss `.ann` plus a ddbj-validator
`validation_report_details.txt`, lists the findings per code with the default operation (`--detect`), and
applies the chosen operations in place on the `.ann` (`--apply`), plus two small gff2mss fixes.

**Architecture:** `src/ann_fix/annfile.py` is a line-exact row model of the `.ann` (every row kept as its 5
tab-separated columns; features are contiguous row ranges) so untouched rows round-trip byte-for-byte.
`report.py` parses validator detail lines into `Finding`s keyed by the 1-based `Line[N]` of the feature's
first row. `operations.py` holds the four operations and the code→default table; `cli.py` wires them.
mRNA↔CDS pairing uses the `note submitter_gene_id: …, submitter_transcript_id: …` qualifier gff2mss writes.

**Tech Stack:** Python 3.11+, stdlib only for ann_fix (no pydantic needed), pytest. Console script `ann_fix`.

**Spec:** `/lustre9/open/home/yt/ddbj/gff_submission/docs/superpowers/specs/2026-10-18-tool-dialect-pipeline-design.md`
§5.3 (ann_fix) and §5.4 (gff2mss fixes).

## Review Focus

1. A validator line without `Line[N]` (file-level `ANN2542:WAR:ALL:ALL:locus_tag:[FILE]:…`) must parse to a
   `Finding` with `line=None` and be listed, not crash the parser. Test in Task 2.
2. A finding whose `Line[N]` points at a feature that an earlier operation in the same run already removed
   (tRNA dropped, then another code names the same tRNA) must be skipped with a notice, not raise. Test in Task 4.
3. A CDS whose paired mRNA is absent (gff2mss `emit_mrna=false`, or nonredundant mode with
   `submitter_transcript_ids`) — `misc` must still convert the CDS alone. Test in Task 3.
4. A `.ann` whose last row has no trailing newline, or has CRLF — round-trip must preserve it exactly. Test in Task 1.
5. `--apply` with a code the report does not contain must be a no-op with a notice, not an error. Test in Task 4.

  pairs, one `tRNA`, copied from the helixer e2e output (first ≈ 60 lines, entry `NC_001133.9`) and edited so a
  tRNA sits inside the second CDS.

**Interfaces:**
```python
@dataclass
class AnnRow:            # exactly one physical line
    cols: list[str]      # 5 columns (padded), no newline
    eol: str             # "\n", "\r\n" or "" (last line)
@dataclass
class AnnFeature:
    entry: str           # entry id (col1 of the first row of the entry block; "COMMON" for COMMON)
    key: str             # col2 of the first row ("CDS", "mRNA", "tRNA", "source", …)
    location: str        # col3 of the first row
    first: int           # 0-based index into AnnFile.rows of its first row
    last: int            # 0-based index of its last row (inclusive)
    def qualifiers(self, rows) -> list[tuple[str, str]]
    def get(self, rows, key) -> str | None
class AnnFile:
    rows: list[AnnRow]
    @classmethod
    def read(cls, path) -> "AnnFile"
    def write(self, path) -> None
    def features(self) -> list[AnnFeature]           # recomputed from rows each call
    def feature_at_line(self, line_1based: int) -> AnnFeature | None
    def replace_feature(self, feat: AnnFeature, key: str, location: str, qualifiers: list[tuple[str,str]]) -> None
    def delete_feature(self, feat: AnnFeature) -> None
    def add_qualifier(self, feat: AnnFeature, key: str, value: str) -> None   # appended after the last qualifier
```
`replace_feature` keeps the entry id in col1 of the first row when the feature was the first of its entry
(and moves it to the next feature when deleting such a feature). `features()` treats a row with non-empty col2
as a feature start; rows with col1 == "COMMON" belong to the COMMON block and are returned as features with
`entry="COMMON"` so callers can skip them.

**Interfaces:**
```python
@dataclass(frozen=True)
class Finding:
    code: str; level: str          # "ERR" | "WAR" | "INF"
    entry: str; feature: str       # as printed ("ALL" allowed)
    line: int | None               # 1-based Line[N] of the feature's first row, None for file-level
    message: str
def parse_details(text: str) -> list[Finding]
def group_by_code(findings) -> dict[str, list[Finding]]   # insertion order = first appearance
```
Line grammar: `^(?P<code>[A-Z]+\d+):(?P<level>ERR|WAR|INF):(?P<entry>[^:]*):(?P<feature>[^:]*):(?:Line\[(?P<line>\d+)\]|[^:]*):(?P<message>.*)$`
(a fifth `:` field such as `locus_tag` may precede `[FILE]`; consume optional qualifier field). Lines that do
not match (headers, blank, `===`) are ignored.

### Task 3: Operations and defaults

**Files:**
- Create: `src/ann_fix/operations.py`
- Test: `tests/test_ann_fix_operations.py` (uses `mini.ann` from Task 1)

**Interfaces:**
```python
ARTIFICIAL_LOCATION_DEFAULT = "low-quality sequence region"
DEFAULTS: dict[str, tuple[str, dict]] = {
    "ANN5320": ("overlap-drop", {"keep": "cds"}),
    "ANN4300": ("misc", {}),
    "AXS6810": ("artificial-location", {"value": ARTIFICIAL_LOCATION_DEFAULT}),
}
IGNORABLE: dict[str, str] = {"ANN2520": "同一遺伝子のアイソフォームが locus_tag を共有（想定どおり）",
                             "ANN2542": "/gene 無しの locus_tag 共有（gff2mss の仕様。放置してよい）"}
OPERATIONS = {"misc", "artificial-location", "drop", "overlap-drop", "overlap-misc"}

def paired_mrna(ann: AnnFile, cds: AnnFeature) -> AnnFeature | None   # same entry, key "mRNA", same submitter_transcript_id in note (fallback: same locus_tag)
def op_misc(ann, feat, **kw) -> str
def op_artificial_location(ann, feat, value=ARTIFICIAL_LOCATION_DEFAULT, **kw) -> str
def op_drop(ann, feat, **kw) -> str
def op_overlap_drop(ann, feat, keep="cds", **kw) -> str
def op_overlap_misc(ann, feat, keep="cds", **kw) -> str
def apply(ann: AnnFile, findings: list[Finding], choice: dict[str, tuple[str, dict]]) -> list[str]  # returns one log line per action/skip
```
Semantics (spec §5.3):
- `misc` on a CDS: replace it by `misc_feature` with the same location; qualifiers = `locus_tag` (kept),
  `note "nonfunctional CDS (<reason>)"` where reason = the finding's code + message head (e.g. `ANN4300: Complete CDS must be at least 90 bases`),
  then any existing `note` rows; drop `transl_table`, `codon_start`, `product`, `gene`, `inference`,
  `transl_except`, `artificial_location`. Delete the paired mRNA (if any). On an mRNA finding, act on its paired CDS.
- `artificial-location VALUE`: `add_qualifier(feat, "artificial_location", VALUE)` on the CDS **and** its paired mRNA; no-op if already present with that value.
- `drop`: delete the feature and its paired mRNA/CDS.
- `overlap-drop keep=cds|other`: for ANN5320 the finding is on the tRNA; `keep=cds` deletes the tRNA; `keep=other` deletes the CDS (+ paired mRNA) named in the message (`in CDS <location>` → locate by `(entry, "CDS", location)`).
- `overlap-misc keep=…`: same selection, but the losing side goes through `misc` (a tRNA becomes `misc_feature` keeping `locus_tag`, `product`→`note`).
- `apply` processes findings in **descending line order** so earlier row indices stay valid; a finding whose line no longer starts a feature of the expected key is logged `skip: line N no longer matches` (Review Focus 2); codes in `choice` absent from the report are logged `no findings for CODE` (Review Focus 5).

- Test: `tests/test_ann_fix_cli.py`

**Interfaces:**
`ann_fix --ann FILE --report DETAILS [--detect [--json]] [--apply CODE=OP[:ARG],...] [--out FILE]`
- `--detect` (default when `--apply` absent): print per code: `CODE  LEVEL  n=<count>  default=<op or "ignore (<reason>)">`
  then up to 5 example lines `  Line[N] <key> <location> <locus_tag>`; `--json` prints
  `[{"code","level","count","default","examples":[{"line","key","location","locus_tag"}]}]`. Exit 0.
- `--apply ANN4300=misc,ANN5320=overlap-drop:other,AXS6810=artificial-location:"low-quality sequence region"`:
  `CODE=OP` uses the op's default kwargs; `:ARG` sets `keep` for overlap ops and `value` for artificial-location.
  `--apply defaults` selects `DEFAULTS` for every code present. Writes to `--out` (required with `--apply`; may equal `--ann`).
  Prints the log lines, then `re-validate: ddbj-validator ddbj <dir> -o <dir>_out -f -j 1`. Exit 0; exit 2 on unknown OP or malformed spec.
